# Pterodactyl Hosting Setup

Repository scaffold for deploying a **Pterodactyl Panel + Wings** game-server hosting system.

> **Status:** Documentation and development workspace scaffold only. This repository does not provision a VPS, create DNS records, install services on a remote host, or start a production panel by itself.

## Architecture
- **Panel** — web UI and API, hosted on a persistent Ubuntu server.
- **Wings** — daemon installed on each game-server node; connects to the Panel using a node configuration generated by the Panel.
- **Database + cache** — MariaDB/MySQL and Redis as required by the current Panel installation guide.
- **GitHub Codespaces** — development/editing environment only, not the production host.

## Before deployment
1. A supported, clean Ubuntu LTS VPS for the Panel.
2. A separate VPS for Wings (or a suitable second host/node) with Docker and required ports available.
3. A domain/subdomain for the Panel, DNS pointing to the Panel host, and HTTPS.
4. A domain/subdomain for each Wings node if using TLS.
5. Access to your VPS provider's console/SSH and permission to administer the servers.

Do not commit API keys, database passwords, Panel application keys, node tokens, SSH private keys, or Wings configuration files to this repository.

## Installation approach
Follow the current official documentation and verify supported versions before installing:
- Panel: https://pterodactyl.io/panel/1.0/getting_started.html
- Wings: https://pterodactyl.io/wings/1.0/installing.html
- Panel configuration: https://pterodactyl.io/panel/1.0/configuration.html

High-level sequence:
1. Prepare and secure the Panel VPS.
2. Install the Panel and its database/cache dependencies using the official guide.
3. Configure the Panel domain and HTTPS.
4. In the Panel, create a node and allocations.
5. Install Wings on the node VPS.
6. Generate the node configuration in the Panel and transfer it securely to the Wings host.
7. Start Wings as a system service, then verify it reports online in the Panel.
8. Create an egg/server and test a game server.

**Do not reuse example secrets or copy node tokens into Git.** Use your VPS provider's secure console or SSH and keep secrets on the target host.

## Codespaces
Open this repository on GitHub and choose **Code → Codespaces → Create codespace on main**. Codespaces is for editing this project; the production Panel/Wings services must run on persistent VPS infrastructure.
